# DATA STRUCTURES SEMESTER PROJECT

## Overview
A C++ dictionary project using data structures (trie tree and hash table concepts).

## Key Files
- `main.cpp`: main implementation and entry point.
- `Dictionary.txt`: dictionary data source..
- `DATA STRUCTURES SEMESTER PROJECT.sln` / `.vcxproj`: Visual Studio project files.

## Build (Visual Studio)
1. Open `DATA STRUCTURES SEMESTER PROJECT.sln`.
2. Select `Debug|x64` (or your preferred configuration).
3. Build and run.
