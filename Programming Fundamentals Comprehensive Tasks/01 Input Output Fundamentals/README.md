# 01 Input Output Fundamentals

- Character To ASCII Code.cpp: Reads one character from input and prints its ASCII integer value.
- Fractional Part Extractor.cpp: Takes a floating-point number and displays only its fractional part by subtracting the integer part.
- Increment Decrement Demo.cpp: Increments an entered number five times and then decrements it three times to show operator effects.
- Multiply Then Add Ten.cpp: Multiplies two input numbers and adds 10 to produce the final result.
- Personal Details Output.cpp: Prints hardcoded personal profile details such as name, age, roll number, and preferences.
- Personal Introduction Display.cpp: Prints a hardcoded short personal introduction with city and area information.
- Pre Post Increment Expressions.cpp: Evaluates three expressions that mix pre-increment and post-increment operators on three variables.
- Quotient And Remainder.cpp: Computes and prints quotient and remainder from dividend and divisor input values.
- Reverse Three Digits.cpp: Accepts three digits separately and prints them in reverse order.
- Subject Marks Average.cpp: Attempts to average five subject marks but currently contains overwritten-input variable bugs.
- Swap Without Temp Variable.cpp: Swaps two integers using arithmetic operations without a temporary variable.
