# 07 Number Theory and Math

- Armstrong Numbers From 1 To 600.cpp: Iterates from 1 to 600 and prints numbers that satisfy the Armstrong-number condition.
- Binary Ones Counter With Digit Bounds.cpp: Counts the number of 1 digits in binary-style input only when total digit count is within allowed bounds.
- Even Odd Sum Difference.cpp: Computes separate odd and even sums up to an upper limit and prints their difference.
- Exponential Series Sum Calculator.cpp: Attempts to evaluate an exponential-style x^n/n! series over terms, but currently has term-calculation flaws.
- Mixed Input Palindrome Checker.cpp: Provides overloaded palindrome checks for string and numeric input, with the numeric branch still incomplete.
- Number To Words Converter.cpp: Converts digits of a number into English word output through digit-wise mapping.
- Shape Area Overloading.cpp: Uses overloaded functions to calculate areas for multiple geometric shapes from user input.
