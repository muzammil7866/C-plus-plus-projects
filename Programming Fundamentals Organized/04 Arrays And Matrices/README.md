# 04 Arrays And Matrices

- Armstrong Numbers In Random Array.cpp: Generates random array values and prints the values that satisfy Armstrong-number logic.
- Centered Number Pyramid.cpp: Prints a centered numeric pyramid with mirrored increasing-decreasing values in each row.
- Frequency Count In Array Alternative.cpp: Contains an alternative attempt at maximum-frequency detection with incomplete counting logic.
- Frequency Count In Array.cpp: Counts frequency of array values and reports the most frequently occurring element.
- Largest In Array.cpp: Reads array values and finds the maximum value.
- Majority Element In Array.cpp: Searches for an element appearing more than half the array size.
- Matrix Half Selection.cpp: Displays upper or lower half of a 4x4 matrix based on user choice.
- Matrix Multiplication And Inverse Check.cpp: Multiplies two 2x2 matrices and checks whether the product is an identity matrix.
- Matrix Transpose.cpp: Builds and prints the transpose of a matrix by swapping row-column positions.
- Palindrome Word Check Using Array.cpp: Attempts palindrome checking with a char array but still has comparison logic issues.
- Replace Array Value.cpp: Replaces all occurrences of a chosen array value with a new value.
- Reverse Number Using Array.cpp: Reverses numeric digits by storing and reconstructing them through array positions.
- Second Largest In Array.cpp: Finds both the largest and second-largest elements in an array.
- Square Matrix Diagonal Extractor.cpp: Keeps main diagonal entries and zeroes non-diagonal entries for a square matrix.
