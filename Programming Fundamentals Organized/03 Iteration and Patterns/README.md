# 03 Iteration and Patterns

- Conditional Number Repeat Pattern.cpp: Repeats a number n/2 times if divisible by 5, otherwise repeats it n/3 times.
- Diamond Pattern Printer.cpp: Prints a symmetric diamond-like pattern using @ characters.
- Filled Square Pattern.cpp: Prints a filled square of stars for the user-provided size.
- Inverted Triangle Pattern For Loop.cpp: Prints an inverted right triangle using nested for loops.
- Numeric Palindrome Pyramid.cpp: Prints rows of ascending then descending numbers to form palindrome pyramid lines.
- Prime Numbers In Range While Loop.cpp: Lists prime numbers within a user-specified range using while-loop checks.
- Right Aligned Triangle Pattern.cpp: Prints a right-aligned triangle by combining spacing and star loops.
- Right Triangle Pattern While Loop.cpp: Prints a basic increasing right triangle pattern using while loops.
- Shape Pattern Menu.cpp: Runs a menu-driven pattern printer for multiple filled and hollow shape choices.
