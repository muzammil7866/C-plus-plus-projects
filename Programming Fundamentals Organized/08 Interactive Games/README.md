# 08 Interactive Games

- Math Quiz Game.cpp: Runs a three-question random arithmetic quiz with limited retries and end-of-quiz feedback.
- Matrix Game Grid Setup.cpp: Initializes a 3x3 game matrix structure but does not yet implement playable game logic.
- Number Guessing Game.cpp: Lets the user guess a random number from 1 to 100 with higher/lower hints and limited turns.
- Random Five By Five Board Generator.cpp: Generates and prints a 5x5 board filled with random numbers from 1 to 25.
- Tic Tac Toe Two Player.cpp: Implements a two-player tic-tac-toe game with turn handling, occupancy checks, and win/tie detection.
