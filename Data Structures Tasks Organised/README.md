# Data Structures and Algorithms Reference Library

A comprehensive C++ collection of 96 programs demonstrating core data structures and algorithms organized by implementation type and problem domain.

## Overview

This library contains implementations of:
- **Core Data Structures:** Arrays, Linked Lists, Stacks, Queues, Graphs, Trees, Hash Tables, Heaps
- **Classic Algorithms:** Searching, Sorting, Graph Traversal, Tree Operations, Expression Evaluation
- **Problem Patterns:** Recursion, Dynamic Arrays, String Manipulation, Matrix Operations
- **Optimization Techniques:** Open Addressing, Separate Chaining, Collision Resolution, Tree Balancing

## Folder Structure (10 Categories)

### 1. [Array Problems And ADTs](Array%20Problems%20And%20ADTs/)
**Focus:** Array manipulation, dynamic arrays, polynomial operations, statistics

**Subfolders:**
- `Dynamic Array ADTs/` - Dynamic array implementations and abstractions
- `Array Rearrangement/` - Array element rearrangement algorithms
- `Array Statistics/` - Mean, median, standard deviation, statistical operations
- `Polynomial and Sequence Problems/` - Polynomial arithmetic, sequence operations
- `Searching and Sorting/` - Search algorithms (binary, linear), sorting techniques
- `String Matrix Experiments/` - 2D string arrays, matrix operations

**Key Concepts:** ADT design, dynamic memory, algorithm complexity, statistical computing

### 2. [Graph Algorithms And Representations](Graph%20Algorithms%20And%20Representations/)

**Key Concepts:** Hash functions, collision resolution, load factors, performance analysis

## Compilation Notes

### Basic Compilation:
```bash
g++ -std=c++11 filename.cpp -o output_name
./output_name
```

### With Optimization:
```bash
g++ -std=c++17 -O2 filename.cpp -o output_name
```

### Debug Mode:
```bash
g++ -std=c++11 -g filename.cpp -o output_name
gdb ./output_name
```

All files follow **Title Case naming** with **meaningful descriptions**:
