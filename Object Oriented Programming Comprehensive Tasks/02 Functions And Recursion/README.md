# 02 Functions And Recursion

## Files
- `AlphabetFrequencyCounter.cpp`: Counts alphabet frequencies from user input while treating uppercase/lowercase as the same letter. It walks characters and updates a dynamic counting structure.
- `FourDigitReverseCalculator.cpp`: Reverses a four-digit number by isolating each digit and rebuilding the number in reverse order. The logic is positional and arithmetic-driven.
- `RandomArrayOddMultipleAnalysis.cpp`: Generates a random array, then prints values at odd indices and values from indices divisible by both 3 and 5. It demonstrates index-filtered traversal.
- `RecursiveDigitSum.cpp`: Recursively sums digits by taking `num % 10` and calling itself on `num / 10` until the base case is reached. This is a clean divide-and-reduce recursion pattern.
- `ReverseDigitThroughFunction.cpp`: Reverses a number iteratively using modulo and division in a loop. Each iteration appends one extracted digit into the new number.
- `SmallestNumberInArray.cpp`: Reads a fixed set of numbers and tracks the minimum value during traversal. The result is the smallest entered element.
- `ThreeDMomentumCalculator.cpp`: Computes momentum components in 3D by multiplying velocity vector components with scalar mass. The output is a component-wise momentum vector.
- `TowerOfHanoiMoveCounter.cpp`: Uses recursive Tower of Hanoi transitions and increments a move counter at each transfer. It prints both move sequence and total moves.
