# 01 Basics And Control Flow

Small programs in this folder focus on condition checks and loop-driven output.

## File Descriptions
- `ElectricityBillCalculator.cpp`: Reads previous/current meter values, computes consumed units, and applies slab-based billing rates. It also guards against invalid negative usage before printing total cost.
- `LogicalConditionsDemo.cpp`: Evaluates a sequence of boolean expressions using relational and logical operators, then prints `true/false` outcomes. The file demonstrates how combined `&&`/`||` conditions behave at runtime.
- `StarPatternGenerator.cpp`: Uses nested loops to print four star patterns: increasing triangle, decreasing triangle, right-aligned increasing, and right-aligned decreasing. The shape progression is controlled by row/column and spacing loops.

Total source files: 3
