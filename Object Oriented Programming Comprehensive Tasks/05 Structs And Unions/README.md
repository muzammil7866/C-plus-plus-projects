## Files
- `AccountStructPointerAccess.cpp`: Uses struct fields through pointer-style access and performs value-level operations. It demonstrates structured record handling with indirection.
- `AccountStructSumWithPointers.cpp`: Aggregates numeric fields from multiple struct records via pointer access. The final output is computed from combined members.
- `EmbeddedAddressStructDemo.cpp`: Defines nested struct composition (e.g., employee with address) and prints embedded member data. It showcases hierarchical record modeling.
- `EmployeeNestedAddressStruct.cpp`: Builds employee data with nested address structure and displays composed details. It demonstrates multi-level struct field access.
- `MonthlyRainfallStructAnalysis.cpp`: Stores month-wise weather values in struct array and computes yearly averages/statistics. It combines record storage with summary analytics.
- `PersonAddressBookStructArray.cpp`: Organizes person/address-like records in array form and processes them sequentially. It focuses on structured batch traversal.
- `PersonArrayWithAddressStruct.cpp`: Constructs and prints structured entries with per-person address information. Output reflects field-wise object-style records.
- `StructUnionMemoryComparison.cpp`: Compares how struct allocates separate member storage versus union shared memory space. It highlights memory footprint behavior.
- `UnionMemoryOverlayDemo.cpp`: Assigns different union members and shows how latest assignment overlays previous data. It demonstrates shared-memory semantics.
- `UnionSearchAndSizeDemo.cpp`: Partially implements record lookup while contrasting struct/union usage. It serves as a mixed memory-and-search concept exercise.
- `WeatherStructArrayPointerOps.cpp`: Uses pointer access over an array of weather structs to read and report monthly values. It mixes structs, arrays, and pointers.
