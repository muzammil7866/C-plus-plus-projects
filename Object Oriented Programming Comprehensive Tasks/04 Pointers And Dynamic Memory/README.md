# 04 Pointers And Dynamic Memory

## Files
- `ArrayAddressesWithPointers.cpp`: Iterates through array with pointer increments and prints both values and addresses. It shows direct memory-location visibility.
- `ArrayCenterSwapPointers.cpp`: Swaps symmetric elements from ends toward center using pointer/index arithmetic. It effectively mirrors the array around midpoint.
- `DoublePointer2DArrayAccess.cpp`: Accesses 2D array elements through double-pointer style dereferencing. Traversal is done row by row with pointer movement.
- `DoublePointerDemo.cpp`: Demonstrates pointer-to-pointer relationships and how value/address chains are resolved. It focuses on indirection levels.
- `DynamicAllocationPointerPractice.cpp`: Allocates memory dynamically for scalar/array values and initializes them at runtime. It highlights allocation, access, and pointer assignment flow.
- `DynamicArrayAllocationDemo.cpp`: Creates a dynamic array and initializes each element through looped pointer-based indexing. It is a compact DMA initialization example.
- `PointerArithmeticModifier.cpp`: Reads/stores data and walks through it using pointer arithmetic instead of direct indexing. The output confirms pointer-driven traversal.
- `PointerArrayAccess.cpp`: Prints array elements by moving a pointer across contiguous memory. It demonstrates equivalent behavior to indexing using dereference syntax.
- `PointerArrayTraversal.cpp`: Sequentially traverses an array while showing current element and memory address. It is a step-by-step pointer movement demo.
- `PointerFunctionParameterDemo.cpp`: Uses reference/pointer-style parameter passing to swap or modify values from caller scope. It illustrates pass-by-reference effect clearly.
- `PointerIncrementBehaviorDemo.cpp`: Compares pre/post increment-decrement behavior with pointers and dereferenced values. It shows operation order impact.
- `PointerValueManipulation.cpp`: Reassigns pointers and updates underlying values through indirection. It demonstrates aliasing and shared-memory updates.
- `PrimeCheckWithPointers.cpp`: Receives number by pointer/reference-like access and checks primality through divisibility tests. Output depends on factor detection.
- `ProducerConsumerBufferSimulation.cpp`: Simulates producer-consumer behavior over a buffer with generation/consumption steps. It models data-flow timing and state updates.
- `VoidPointerTypeCastingBasics.cpp`: Stores an address in `void*`, then casts back to concrete pointer type for valid operations. It demonstrates generic pointer handling.
