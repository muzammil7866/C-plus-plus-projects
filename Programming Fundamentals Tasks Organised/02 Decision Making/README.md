# 02 Decision Making

- Bank Account Balance Updater.cpp: Updates balance using account type rules, applying service charge or interest based on minimum-balance checks.
- Boolean Condition Flow.cpp: Runs conditional boolean assignments and then changes variable values according to evaluated outcomes.
- Boolean Expression Evaluator.cpp: Computes and prints the results of multiple logical expressions using preset variable values.
- Cable Bill Calculator.cpp: Calculates cable bill for residential or business customers using premium channel and connection logic.
- Conditional Increment Decrement.cpp: Increments input only when it is 3 and decrements only when it is 4.
- Cookie Packaging Calculator.cpp: Calculates number of cookie boxes and containers plus remainders under packaging constraints.
- Customer Spending Classifier.cpp: Classifies repeated customer spending entries into ranges and accumulates totals per category.
- Days To Hours Minutes Converter.cpp: Converts entered days into hours or minutes depending on user selection.
- Employee Bonus Eligibility Calculator.cpp: Determines employee bonus percentage from gender, age, and basic pay criteria.
- Largest Number Tracker.cpp: Repeatedly accepts numbers and tracks the largest number entered so far.
- Month Days Lookup.cpp: Returns month day counts using switch logic with fixed February days.
- Month Days With Leap Year.cpp: Returns month day counts with leap-year adjustment for February.
- Non Zero Number Division.cpp: Divides larger by smaller for non-zero inputs or multiplies if both numbers are equal.
- Number Guessing Game.cpp: Runs a random number guessing game with high/low hints until the correct guess is entered.
- Syntax Fix Demo.cpp: Demonstrates corrected syntax for constants, if-else blocks, and operator usage.
- Triangle Pattern Menu.cpp: Shows a menu that prints different triangle styles based on the chosen option.
- Vowel Consonant Checker.cpp: Identifies whether the entered alphabet character is a vowel or consonant.
- Work Area Eligibility Checker.cpp: Decides whether a person can work in urban areas or any area based on gender and age.
