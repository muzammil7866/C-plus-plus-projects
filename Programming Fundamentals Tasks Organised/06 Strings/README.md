# 06 Strings

- Caesar Shift Cipher.cpp: Shifts each character by one alphabet position with wraparound handling for z and Z.
- Capitalize Words.cpp: Capitalizes the first character of the sentence and every character after a space.
- Concatenate Two Strings.cpp: Reads two strings and prints them as one combined string with a space separator.
- Day Number From Date.cpp: Parses a month-day-year string and calculates its day number in the year with leap-year handling.
- Lexicographic Minimum Character.cpp: Sorts string characters in ascending lexical order using a selection-sort style approach.
- Longest Word Length.cpp: Finds and prints the longest word and its length from a sentence.
- Palindrome String Check.cpp: Compares characters from both ends to determine whether the input string is palindrome.
- Reverse String.cpp: Prints a word in reverse character order.
- Reverse Words In Sentence.cpp: Reverses the order of words in a sentence while preserving each word’s internal characters.
- String Input.cpp: Reads a full string input and echoes it back to the console.
- Substring Search In Text.cpp: Finds a substring inside text and reports the starting index or not-found message.
