# 05 Functions

- Dice Roll Simulator Function.cpp: Simulates repeated dice rolls through a function and accumulates score until the user stops.
- Fibonacci Sequence Function.cpp: Prints the Fibonacci sequence up to the number of terms requested by the user.
- Function Overloading Swap Demo.cpp: Starts a function-overloading swap demo but remains incomplete in main flow.
- Max Of Three Using Function.cpp: Uses a dedicated function to return the largest of three input integers.
- Multi Utility Functions.cpp: Combines multiple utility functions such as digit reversal, multiple check, character shift, and case conversion.
- Number Palindrome Function.cpp: Uses a function to check whether an entered number is palindrome.
- Power Equality Check Function.cpp: Repeats input until a function confirms num3 equals num1 raised to power num2.
- Prime Numbers In Range Function.cpp: Uses a function to print prime numbers between two given bounds.
- Series Sum With Factorial Function.cpp: Computes the series sum n/n! for n from 1 to 7 using helper functions.
